💡   Context

Introduction

Today, discovering authentic local places relies heavily on word-of-mouth or mainstream tourist apps that miss hidden, local gems.

  • Urban explorers lack a dedicated, community-driven platform.
  • No structured way to categorize, rate, and save secret spots.
  • Existing social media doesn't offer geolocation + review features together.

Hidden Spots Finder bridges this gap with a full-stack PHP web application.

The Problematic

❌   Without Hidden Spots

  • Local gems stay unknown — buried in generic platforms.
  • No community feature for photo sharing + geolocation together.
  • Manual sharing via WhatsApp/Instagram — disorganized.
  • No personal space to save favorites or manage your own spots.

✅   With Hidden Spots

  • A dedicated community platform for local explorers.
  • Centralized place with categories, search, and filters.
  • Complete user profile management & favorites system.
  • Server-side image upload, AJAX interactions, secure auth.

Technologies Used

🌐   Frontend (Client)

  • HTML5 — Semantic structure, SEO-ready markup
  • CSS3 — Custom properties, Flexbox, Grid, animations
  • Vanilla JS (ES6) — DOM, AJAX (Fetch API), CSRF tokens
  • Playfair Display + Inter — Premium typography

🖥️   Backend (Server)

  • PHP 8.x (OOP) — Models, actions, session management
  • MySQL + PDO — Prepared statements, ON DUPLICATE KEY
  • MVC Architecture — Pages / Classes / Actions separation
  • File System — Multipart image upload to /uploads/
🔒 Password hashing (bcrypt) 📄 Server-side pagination 🛡️ XSS & CSRF Protection 🔄 Singleton DB Pattern

Project Architecture

📁 File Structure

hidden-spots/
├── classes/    OOP Models
User · Place · Review · Favorite
├── pages/      Views (PHP)
auth/ · places/ · profile/
├── actions/    Controllers / API
auth · place · review · favorite
├── assets/     CSS · JS · Images
├── includes/   header · footer
└── config/     DB Singleton

🔁 Request Flow

Browser → index.php → Page (View) → instantiates Model → queries Database via PDO → renders HTML

⚡ AJAX Flow

JS (Fetch) → actions/ controller → JSON response → DOM update (no page reload)

🗄️ Database

Singleton Database class returns a single PDO instance. All queries use prepared statements.

Conclusion & Prospects
