# AYOUB ELFAQUIHI — Premium Portfolio

Modern, recruiter-friendly portfolio built with **React + Tailwind CSS + Framer Motion**.

## Requirements

- Node.js (LTS recommended)

## Setup

```bash
cd ayoub-portfolio
npm install
npm run dev
```

## Theme system

- Tailwind `darkMode: "class"`
- Theme persisted in `localStorage` under `ayoub.theme`

## Resume

Replace `public/resume.pdf` with your real PDF resume (keep the same name).

## Contact form (production)

Set `VITE_CONTACT_ENDPOINT` to your secure endpoint (serverless / API) to receive messages.
